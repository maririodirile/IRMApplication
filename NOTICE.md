The form and hub also contain a 54-statement enterprising tendency assessment (GET2) and a 12-statement grit scale. Confirm that NBI holds permission to use these instruments in the programme.

## Personal information

Application data includes ID numbers, contact details and business information about individuals. Handle it in line with POPIA. Do not commit exports or application files to this repository (the `.gitignore` excludes the usual file names).
